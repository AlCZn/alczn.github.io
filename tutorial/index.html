HTML 入门教程

学习如何创建网页结构

一、什么是 HTML？

HTML 是“超文本标记语言”（HyperText Markup Language）的缩写， 用于定义网页的结构和内容。

HTML 使用标签描述内容，例如使用 <h1> 表示标题，使用 <p> 表示段落。

二、HTML 文档基本结构

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>我的网页</title>
</head>
<body>
    <h1>欢迎来到我的网页</h1>
</body>
</html>
  • <!DOCTYPE html>：声明 HTML5 文档。
  • <html>：网页的根元素。
  • <head>：存放网页设置和元信息。
  • <body>：存放网页中显示的内容。

八、CSS 入门教程

CSS 是“层叠样式表”，用于设置网页的颜色、字体、间距和布局。 

p {
    color: #1677ff;
    font-size: 18px;
    text-align: center;
}

常用 CSS 属性

  • color：设置文字颜色。
  • background：设置背景。
  • font-size：设置文字大小。
  • margin：设置外边距。
  • padding：设置内边距。
  • border：设置边框。
  • display：设置元素显示方式。

九、JavaScript 入门教程

JavaScript 是一种编程语言，可以为网页添加交互功能。 

const button = document.querySelector("button");

button.addEventListener("click", function () {
    alert("按钮被点击了！");
});

常用 JavaScript 内容

  • const 和 let：声明变量。
  • if：进行条件判断。
  • for：执行循环。
  • function：定义函数。
  • document.querySelector()：获取网页元素。
  • addEventListener()：监听用户操作。

十、HTML、CSS 和 JavaScript 的关系

  • HTML：网页的结构。
  • CSS：网页的样式。
  • JavaScript：网页的行为和交互。

十一、HTML 学习建议

  1. 先掌握常用标签和属性。
  2. 使用语义化标签，如 <header>、<main> 和 <footer>。
  3. 结合 CSS 美化网页。
  4. 学习 JavaScript 实现交互效果。
  5. 经常使用浏览器开发者工具检查页面。

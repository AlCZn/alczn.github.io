HTML 入门教程

学习如何创建网页结构

一、什么是 HTML？

HTML 是“超文本标记语言”（HyperText Markup Language）的缩写， 用于定义网页的结构和内容。

HTML 使用标签描述内容，例如使用 <h1> 表示标题，使用 <p> 表示段落。

二、HTML 文档基本结构

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>我的网页</title>
</head>
<body>
    <h1>欢迎来到我的网页</h1>
</body>
</html>
  • <!DOCTYPE html>：声明 HTML5 文档。
  • <html>：网页的根元素。
  • <head>：存放网页设置和元信息。
  • <body>：存放网页中显示的内容。

八、HTML 学习建议

  1. 先掌握常用标签和属性。
  2. 使用语义化标签，如 <header>、<main> 和 <footer>。
  3. 结合 CSS 美化网页。
  4. 学习 JavaScript 实现交互效果。
  5. 经常使用浏览器开发者工具检查页面。

一、CSS 是什么？

CSS 是 Cascading Style Sheets 的缩写，中文名称为层叠样式表。 它用于控制 HTML 元素的颜色、大小、间距、位置和动画效果。 

选择器 {
    属性: 属性值;
}
p {
    color: blue;
    font-size: 18px;
}

CSS 的核心思想是：选择元素，然后设置样式。

二、CSS 选择器

1. 基础选择器

/* 元素选择器 */
p {
    color: red;
}

/* 类选择器 */
.card {
    padding: 20px;
}

/* ID 选择器 */
#title {
    font-size: 32px;
}

/* 通用选择器 */
* {
    box-sizing: border-box;
}

2. 组合选择器

/* 后代选择器 */
.container p {
    color: blue;
}

/* 子元素选择器 */
.container > p {
    font-weight: bold;
}

/* 相邻兄弟选择器 */
h2 + p {
    margin-top: 0;
}

/* 属性选择器 */
input[type="text"] {
    border: 1px solid blue;
}

3. 伪类和伪元素

/* 用户交互状态 */
a:hover {
    color: red;
}

/* 第一个子元素 */
li:first-child {
    font-weight: bold;
}

/* 在元素前面插入内容 */
.title::before {
    content: "★ ";
    color: gold;
}

三、CSS 盒模型

每一个 HTML 元素都可以看作一个矩形盒子。 盒模型由内容、内边距、边框和外边距组成。 

元素总宽度 =
内容宽度 + 左右内边距 + 左右边框 + 左右外边距
内容区域 
* {
    box-sizing: border-box;
}

使用 border-box 后，元素设置的宽度会包含内容、 内边距和边框，通常更容易控制布局。

四、层叠、继承与优先级

1. 层叠

当多个规则同时作用于一个元素时，浏览器会根据优先级决定最终样式。

2. 优先级

通常优先级从高到低如下：

  1. !important
  2. 行内样式
  3. ID 选择器
  4. 类、属性和伪类选择器
  5. 元素选择器
  6. 通用选择器
/* 不建议滥用 !important */
.title {
    color: red !important;
}

3. CSS 继承

一些属性会自动从父元素继承，例如文字颜色和字体。 盒模型、宽度和高度通常不会自动继承。

五、Flexbox 弹性布局

Flexbox 适合处理一维布局，例如横向排列、纵向排列和居中对齐。 

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
}
  • display: flex：启用 Flex 布局。
  • flex-direction：设置主轴方向。
  • justify-content：设置主轴对齐方式。
  • align-items：设置交叉轴对齐方式。
  • flex-wrap：允许元素换行。
  • gap：设置子元素之间的间距。
  • flex：设置子元素的伸缩比例。

六、Grid 网格布局

CSS Grid 适合处理二维布局，可以同时控制行和列。 

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

七、定位

.box {
    position: relative;
}

.child {
    position: absolute;
    top: 10px;
    right: 10px;
}
  • static：默认定位方式。
  • relative：相对自身原位置偏移。
  • absolute：相对最近的定位祖先元素定位。
  • fixed：相对浏览器窗口固定。
  • sticky：滚动到指定位置后固定。

八、响应式设计

响应式设计可以让网页适配电脑、平板和手机等不同屏幕。 

/* 屏幕宽度不超过 700px 时生效 */
@media (max-width: 700px) {
    .container {
        grid-template-columns: 1fr;
    }

    h1 {
        font-size: 28px;
    }
}

常见方法包括媒体查询、弹性布局、网格布局、 百分比宽度和 clamp() 函数。 

h1 {
    font-size: clamp(2rem, 5vw, 4rem);
}

九、CSS 变量

CSS 变量可以保存颜色、尺寸等常用值，便于统一修改主题。 

:root {
    --main-color: #2563eb;
    --spacing: 20px;
}

.button {
    color: white;
    background: var(--main-color);
    padding: var(--spacing);
}

使用 var(--变量名) 可以读取变量值。

十、过渡、变换与动画

1. 过渡效果

.button {
    transition: background 0.3s, transform 0.3s;
}

.button:hover {
    transform: scale(1.05);
}

2. CSS 动画

@keyframes move {
    from {
        transform: translateX(0);
    }

    to {
        transform: translateX(300px);
    }
}

.box {
    animation: move 3s infinite alternate;
}

十一、常用单位

单位 说明
px 像素，固定单位
% 相对父元素的百分比
em 相对当前元素字体大小
rem 相对根元素字体大小
vw 相对视口宽度
vh 相对视口高度

十二、CSS 编写建议

  1. 优先使用类选择器，避免过度使用 ID 选择器。
  2. 合理使用 CSS 变量统一管理颜色和尺寸。
  3. 优先使用 Flexbox 和 Grid 完成布局。
  4. 避免大量使用 !important。
  5. 使用媒体查询适配不同屏幕。
  6. 保持 CSS 命名清晰，例如使用 BEM 命名方式。
  7. 使用浏览器开发者工具调试样式。
